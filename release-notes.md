## Download EyeClops

Pick the file for your platform - you only need one:

| Platform | File |
|---|---|
| Windows | `EyeClops_..._x64-setup.exe` |
| macOS (Apple Silicon / M-series) | `EyeClops_..._aarch64.dmg` |
| macOS (Intel) | `EyeClops_..._x64.dmg` |
| Linux (Debian/Ubuntu) | `EyeClops_..._amd64.deb` |
| Linux (Fedora/RHEL) | `EyeClops-...-1.x86_64.rpm` |
| Linux (other, portable) | `EyeClops_..._amd64.AppImage` |

The rest of the files (`.msi`, `.app.tar.gz`, source archives) are build artifacts used internally by the updater/packaging tools - safe to ignore unless you specifically need them.
